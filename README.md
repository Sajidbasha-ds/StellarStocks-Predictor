# StellarStocks Predictor

AI-powered stock market analysis and prediction dashboard built using:

- Python
- Streamlit
- Scikit-learn
- Plotly
- Prophet
- Yahoo Finance API

## Features

- Real-time stock analysis
- Machine learning prediction
- Interactive charts
- Portfolio comparison
- Risk metrics
- FAQ chatbot

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
